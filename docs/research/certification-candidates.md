- Checked: **2026-11-01** (Asia/Seoul). This is the date every value below was checked, and the link next to a value is its source.
- See also: [Grade systems by certification](certification-grades.md), [Detailed study plans](../plans/README.md)

## How to read this

- Only official sites were used as evidence. The amounts in the AI recommendation list the user had saved were not used.
- **Could not confirm**: a value for which I found no official evidence. I did not fill it in by guessing.
- **(excerpt)**: a value I saw in an excerpt of an official page in search results because I could not open the page text. Check it again before you pay.
- The exam fee is the Korean price if it is public, and the USD list price if not. Tax may be extra.
- Exam fees change. Check again on the official site when you register.

## Recommended roadmap matched to the current goals

The first 3 stages follow the order of the [Detailed study plans](../plans/README.md), and from stage 4 on it is the author's recommendation. Study time is only 2 hours on holidays and 1 hour on weekdays in the 2 weeks before an exam, so no period is given, and the next stage is decided when the earlier one ends.

| Stage | Certification                                                                                                                  | Reason                                                                                         |
| ----- | ------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| 1     | TOEIC first attempt (2027-01-31 tentative), Engineer Information Processing practical                                          | TOEIC is the timing the user chose, and the practical exam deadline is the 3rd session of 2027 |
| 2     | Driver's license Class 2 Regular, AWS Cloud Practitioner                                                                       | You have no license, and the first AWS level needs no experience                               |
| 3     | TOEIC Speaking, TOEIC second attempt, AWS Solutions Architect – Associate                                                      | The rest of the exams in the current goals                                                     |
| 4     | SQLD, Terraform Associate, KCNA                                                                                                | They cover the basics of databases, infrastructure automation, and containers                  |
| 5     | Choose a direction: security (Engineer Information Security), infrastructure (CKA, AWS Professional), AI (AWS AI Practitioner) | Decide by the work and interests at that time. AWS Professional needs 2 years of experience    |

By user decision the Craftsman and Industrial Engineer grades are not pursued, so the Craftsman Cook in the table below is kept only for reference.
