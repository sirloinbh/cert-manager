| 항목      | 내용                                                                                                                       |

| 등급      | 기능사(프로그래밍기능사) → 산업기사(정보처리산업기사) → 기사(정보처리기사) → 기술사(정보관리기술사 등)                     |

| 응시료    | 정보처리기사 필기 19,400원, 실기 22,600원(민간 자료, 접수 화면에서 확인)                                                   |

| 자료      | 먼저 Q-Net 출제기준을 받는다. 교재는 고를 때 최신 출제기준에 맞는지 확인한다                                               |

## 응시 예정일

**2028년 회차, 미정.** 2027년 시행계획도 2026-10-31 현재 공식 공고를 확인하지 못했다. 2028년 공고가 나오면 회차를 정한다.

모든 등급을 따기로 했으므로 기본 순서는 자격이 필요 없는 기능사부터다. 기사 자격이 이미 되면 기사부터 보는 것도 가능하므로 자가진단 결과를 보고 다시 정한다. 공휴일 2시간만으로는 기사 실기까지 시간이 크게 부족할 수 있다.
